# Beta79 — stone exterior retaining courses

Use the binary JAR for your loader; the sources JAR is for development only.
SHA256SUMS accompanies each pair. No installed profile or live world was changed.

Fresh exterior hillside retaining courses use regular stone instead of polished andesite.
Building/interior blocks, walkway materials and other retaining palettes remain unchanged.
Existing frozen plans and completed walls keep their materials; no blanket block replacement
is performed. All player-placement, claim, inventory and loaded-chunk checks remain active.

Includes the earlier beta78 changes. Architecture remains revision 20 with historical assets
preserved. See docs/reviews/2026-10-07-beta79-stone-retaining-walls.md for verification.
